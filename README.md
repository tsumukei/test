# Sample Static Site

This repository contains a minimal static webpage composed of `index.html`, `styles.css`, and an optional `script.js` that adds a small interactive greeting button.

## Viewing the site

To open the site locally:

1. Download or clone this repository.
2. Locate the `index.html` file at the project root.
3. Double-click `index.html` or open it with your preferred web browser.

The page will display a welcoming message, styled layout, and a button that reveals a random greeting when clicked.
